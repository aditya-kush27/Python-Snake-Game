# 🐍 Python Snake Game

A simple Snake Game developed using Python and Pygame.

## Features

* Classic Snake gameplay
* Arrow-key controls
* Random food generation
* Score tracking
* Game-over screen
* Restart and quit options

## Technologies Used

* Python
* Pygame
* Random module

## How to Run

Install Pygame:

```bash
pip install pygame
```

Run the game:

```bash
python snake_game.py
```

## Controls

* ↑ Up
* ↓ Down
* ← Left
* → Right
* C – Play Again
* Q – Quit
